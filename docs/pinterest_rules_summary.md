## https://policy.pinterest.com/en/terms-of-service
Based on the provided text, the following rules affect an automated Pinterest publishing or curation tool:

* **Unauthorized Automation & Scraping:** You may not scrape, collect, search, copy, or otherwise access data or content from Pinterest using automated means without express prior permission.
* **Unauthorized Third-Party Access:** You may not permit Pinterest to be used by or for the benefit of unauthorized third parties.
* **Tool Restrictions & Reverse Engineering:** You are prohibited from modifying the Service, creating derivative works based on it, reverse engineering it, or copying any of its features or functions.

## https://policy.pinterest.com/en/developer-guidelines
Here are the rules from the provided text that affect an automated Pinterest publishing/curation tool:

* **API Data Storage:** You cannot store information accessed through the API (you must call the API each time), except for campaign analytics on authorized accounts.
* **Credentials & Access:** 
  * Access accounts using authorization tokens only; never solicit or store login credentials, passwords, or session cookies.
  * API credentials must remain private. If using a "bring-your-own-key" model, keys must be stored locally on the user's device, not server-side.
* **Data Usage & Sharing:** API data cannot be sold, shared with third parties, or combined with data from other accounts or services.
* **User Consent for Actions:** Apps cannot perform actions (creating, saving, or editing Pins; following/unfollowing; commenting; messaging) without the user's specific knowledge and consent.
* **Automation Requirements:** 
  * Features cannot automatically initiate actions without the user specifically considering each individual action.
  * Users must explicitly select *each* Pin to be published and *each* account to follow (no unapproved bulk/fully autonomous automation).
* **Policy Evasion:** Apps removed for policy violations cannot be reconnected under a different account or name.
* **Privacy Policy:** You must maintain and link to a legal privacy policy when applying for API access.
