## https://policy.pinterest.com/en/terms-of-service
Based on the provided text, here are the rules that affect an automated Pinterest tool:

* **No unauthorized automation or scraping:** You are prohibited from scraping, collecting, searching, copying, or otherwise accessing Pinterest data or content using automated means without express prior permission.
* **No unauthorized third-party use:** You may not allow Pinterest to be used by or for the benefit of unauthorized third parties.
* **Restrictions on software/service copying:** You may not reverse engineer the Service or copy any of its features or functions.

## https://policy.pinterest.com/en/developer-guidelines
Based on the provided text, here are the rules that affect an automated Pinterest publishing or curation tool:

*   **No Fully Automated Actions:** You must not offer features that automatically initiate actions without the end user specifically considering and choosing each individual action (e.g., the user must manually choose each Pin to be published and each account to follow).
*   **No Unauthorized User Actions:** You cannot take actions on behalf of users—such as modifying profiles, creating, saving, or editing Pins, following/unfollowing, messaging, or commenting—without their specific knowledge and consent.
*   **API Data Storage Restrictions:** You may not store any information accessed through the API (except for campaign analytics information). You must call the API each time you need to access information.
*   **No Sharing/Selling API Data:** You are prohibited from sharing or selling information obtained from the Pinterest API with third parties.
*   **Credentials Security:** Do not solicit or collect user login credentials (passwords, session cookies, etc.). For "bring-your-own-key" applications, user API credentials must be stored locally on the client side, not server-side.
*   **Permitted Tool Types:** Content marketing tools (like Pin schedulers) and dynamic creative tools (which automate content creation) are acceptable integrations, provided they require users to manually authorize publishing actions.
*   **Policy Evasion:** If Pinterest removes your application for a policy violation, you must not attempt to reconnect the same or a similar app using a different account or name.
